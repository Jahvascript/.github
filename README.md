# JahvaScript | Everyone Is Welcome

**Different backgrounds. Different experiences.
One community.**

JahvaScript is an open-source software engineering
initiative welcoming people of all backgrounds,
beliefs, abilities, and experience levels.

The name combines a creative nod to **Jah** in
Rastafari culture with **JavaScript**.
Participation does not depend on religious beliefs
or any particular identity.

We value:
- Peace, respect, and constructive collaboration.
- Learning, creativity, and knowledge sharing.
- Accessibility and inclusive participation.
- Proper attribution and open-source responsibility.
- Helping newcomers feel comfortable contributing.
