# Accessibility and Inclusion

JahvaScript aims to make open-source participation
accessible and welcoming.

We value clear documentation, understandable instructions,
constructive feedback, and multiple ways to contribute.

If an accessibility barrier prevents you from using or
contributing to a project, please open an issue in the
relevant repository or contact jahvascripts@gmail.com.

Accessibility is an ongoing effort, not a claim that
every project is already fully accessible.
